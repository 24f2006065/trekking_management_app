# Trekking Management Application

A Flask and SQLite application for administrators, trek staff, and trekkers.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Start the app: `python run.py`
4. Open `http://127.0.0.1:5000`

The SQLite database and pre-created administrator are generated automatically on first start.

- Admin email: `admin@trek.com`
- Admin password: `admin123`

Trekkers and staff can self-register. Staff must be approved by an administrator before they can log in.
